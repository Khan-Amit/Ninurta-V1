# Ninurta‑V1 Security Protocol

## Slab‑Based Two‑Number SMS + Biometric

| Slab | Amount | Security Required |
|------|--------|-------------------|
| 0 | < $50 | Biometric only |
| 1 | $50 – $500 | SMS to primary number |
| 2 | $500 – $5,000 | SMS to primary + secondary number |
| 3 | > $5,000 | Two SMS + biometric + 1‑hour delay |

## Two‑Number Defence

- Primary number: your everyday phone
- Secondary number: trusted person (spouse, partner, family)

Even if one phone is stolen or SIM swapped, the attacker cannot approve large transfers without the second number.

## Offline Recovery

Pre‑generate 10 one‑time codes, print them, store safely. If both phones lost, use recovery codes + biometric (with 24h delay).

## Theft‑Proof, Hijack‑Proof, Kidnap‑Proof

- **Theft:** thief has only one phone.
- **SIM swap:** attacker misses second number.
- **Kidnap:** you cannot be forced to transfer large amounts without the second person's code.
